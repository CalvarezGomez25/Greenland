## Límites de esta memoria

- Las conversaciones anteriores a la sesión de desarrollo (donde nacieron el libro, la especificación inicial y los prototipos) **no se pudieron leer**. La fase 0 de la historia se reconstruye de los artifacts y de la especificación.
- Los sitios de los editores (PMI, ISO, etc.) **no se pudieron abrir**; el marco teórico se apoya en resultados de búsqueda y lo dice.
- Las fichas de decisión se redactaron **después** de las decisiones, a partir del registro.
