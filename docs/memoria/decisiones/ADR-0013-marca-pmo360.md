# ADR-0013 · Marca: PMO360 · Control integral de Proyectos

| Campo | Valor |
| --- | --- |
| Estado | Aceptada y vigente |
| Fecha | 2026-10-10 |
| Quién decidió | Usuario |

## Contexto
«Plataforma de obra» se consideró genérico. El usuario pidió un nombre profesional y creativo, «algo como PMO360», y varias propuestas.

## Alternativas consideradas
Otras propuestas presentadas en la sesión (no se conservaron en esta memoria).

## Decisión
Nombre PMO360, mensaje «Control integral de Proyectos» bajo el título; el logo de GreenLand queda como imagen principal sin repetir el nombre.

## Consecuencias
El nombre admite una lectura de «vuelta completa» (360°) que se usó después para unir la plataforma con FARO ([ADR-0019](ADR-0019-faro-y-piloto-de-90-dias.md)).

## Evidencia
Commit `63ac198`.
